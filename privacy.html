Privacy policy

Nutrition Agent is a personal application used only by its developer.

It reads the developer's own Google Health data (sleep, steps and weight) with read-only access.

The data is stored only on the developer's own private server and is never sold, shared or disclosed to anyone.

The use of Google user data is limited to providing this personal tracking feature, in line with the Google API Services User Data Policy, including its Limited Use requirements.
